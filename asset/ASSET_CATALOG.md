# Of All The Russias — Visual Asset Catalog

This catalog is the source list for the runtime art library in `src/event-art.js`.

The project deliberately favors public-domain and openly licensed material from Wikimedia Commons. Runtime currently uses Commons `Special:Redirect/file/...` URLs so the art can be swapped without rebuilding the game-data layer. Later we can vendor optimized local copies into `/asset/` once the selection is locked.

## Olga Shirnina / Klimbim

Olga Shirnina (Klimbim) is useful for the **Good Queen Olga** route and potentially family scenes because her colorizations make the Romanovs feel immediate rather than archival.

Her site explicitly says: **“All images colored by me can be used for free for any purposes but commercial.”** Because that is a non-commercial-only permission, Klimbim work is **not loaded into the default runtime asset library**. It may be used in a non-commercial build if the project remains non-commercial and the image is credited appropriately.

Particularly applicable pages:

- `Grand Duchess Olga Nikolaevna | Великая княжна Ольга Николаевна, 1913` — Klimbim colorization.
- `GD Olga | ВК Ольга` — Klimbim colorization.
- `Grand Duchess Olga Romanov | Великая княжна Ольга` — Klimbim colorization.
- Klimbim tag archive: `Grand Duchess Olga of Russia`.

Do **not** silently copy Klimbim images into `/asset/` until the project’s commercial/noncommercial status is settled. The original underlying historical photographs may be public domain, but her colorization itself carries the stated non-commercial condition.

## Runtime treatment

`src/event-art.js` maps individual question numbers to images. `src/event-art.css` places the image behind each question as a darkened archival plate rather than a bright illustration. Advisor portraits are also swapped according to the active adviser.

The art should feel like evidence from an imperial dossier, not a slideshow: dark forest-green overlay, gold framing, low saturation, selective brightness, and high contrast. Full-color or restored material should be used sparingly enough that it feels uncanny when it appears.
